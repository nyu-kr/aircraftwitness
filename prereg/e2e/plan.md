## Population and sample

- Frame: the 3,912,415 labelable public-audio recording rows in snapshot `v2-20261105T1126`, with usable source time and published place and inside the frozen ADS-B archive coverage. There is no aircraft-label/pass condition. The independent custodian builds this from the source manifests, never by joining to positive pass labels. The custodian receives the frozen snapshot and source-manifest paths privately; identifying paths are not published.
- The independent custodian records mutually exclusive out-of-scope counts and priority, including no public audio, unusable source time, missing/invalid place, obscured/coarse place outside the frozen labelability rule, outside archive dates and no frozen finalisation day. Frozen source-derived end-day coverage determines eligibility, not pass content. Sampling day is separately the source's own UTC start day. A reconstructed count different from 3,912,415 must be resolved before freezing. Within-frame fetch failures, unreadable audio and no-answer are misses, never exclusions.
- Two-stage keyed sample, prev's systematic PPS design, new key `AircraftWitness-e2e-20261105-v1`: 160 day draws, 10 recordings per draw, nominal n=1,600. HMAC-SHA256's first unsigned 64 bits define H in [0,1). Stage 1: UTC source-start days in keyed `day:{day}` order, size N_day; systematic points `(H("start")+j)*N/160`, j=0..159. Stage 2: a day's records sorted by source, `H("rec:{opaque_row}")`, opaque_row; sample min(N_day,10*day_hits) systematic records with offset `H("s2:{day}")`, interleaved across that day's draw hits, exactly as prev. Removing the labelled distance/altitude strata and label day is required by the new frame, not outcome tuning. The position-independent opaque assignment and frame hash are frozen before this draw. The sampler reads exactly opaque_row, day, source and nullable duration_s; no site identity, position, label or flight statistic enters it.
- Sampler `bin/sample.py` SHA256 `888702e23d840f86acbbc8710b754a3d8f0f2585bfc96067a0a8614b35f9c105`; the actual command and output hash receipt were exercised on synthetic inputs on Torch before freezing. No study audio was used.
- Draw order is j=0..159, then within-draw index. Do not sample a replacement for a failed recording. A day with fewer than ten recordings contributes its available records; report actual n. The self-weighted estimator is the mean within-draw hit share, with 1/m_j occurrence weights for a short draw. Source and detector-positive estimates are the corresponding weighted domain ratios. A domain with zero denominator is not estimable.
- Precision planning: p=1%, nominal n=1,600 and design effect 2 give effective n=800. The expected 95% Wilson interval for 8/800 is 0.5076% to 1.9608%, about plus or minus 1 percentage point. This is a planning assumption, not guaranteed precision by source/place or power to distinguish 1% from pi/400. Report achieved interval widths and actual design effects. Prior-run cost scales to about 234 allocated core-hours; first-hour transfer/scan cost is additional and not yet measured on this frame.

## Packets and audio-only windows

- A recording of at most 300 s is supplied whole. For a longer recording, only the first min(source duration,3,600 s) is eligible for scanning and window choice. Never seek to a labelled pass, scan beyond the first hour or download a huge file whole just to select a window. Use the source segment API, HTTP range requests or streaming prefix decode where supported; close the transfer after the eligible prefix. An unsupported prefix fetch/decode is an explicit failure and miss, not permission to fetch an unbounded file. Unknown manifest duration remains null until prefix decoding determines the available duration, capped at 3,600 s; do not silently substitute the first 300 s.
- Shared detector: `dopplerprint discover` 0.1.0, source `447dbed`, default parameters, the same discover used by the frozen reference. No --params/--wins/--f-max/--mains override, no flights, square, time, position or labels. Core SHA256 `d4a4c20129f60bf86542f80c2b9aaae55a5e379c27f92432ad3b4c55b52c3b28`. Mono FLAC and above-96-kHz resampling to 48 kHz follow prev. Run it on the eligible audio prefix, also on short recordings to define the shared detector-positive flag; fixed scan wall limit 900 s.
- For a usable discover event, choose the longest `max(ridge.t)-min(ridge.t)`, then greatest finite snr, then earliest finite `fit.best.t_cpa_arrive`, then event id. Usable means finite nonempty ridge times and finite fitted arrival time. For eligible prefix duration T>300, offset is clamp(t_cpa_arrive-150,0,T-300), floored to milliseconds; supply 300 s. This is `window_rule=detector`. For T<=300, offset 0 and rule `whole`.
- If discover succeeds with no usable event, choose offset `floor(1000*(T-300)*H("window:{opaque_packet}"))/1000`, rule `random_no_pass`. If discover errors/times out but audio is readable, use the same random fallback, rule `random_detector_error`, detector status unknown. The domain flag means at least one usable discover event in the eligible prefix, not a true/audible aircraft label. Record original/prefix duration, scan cap, rule, offset, detector status/count and scan wall time. Fetch/decode failure is a miss, with no truth-based fallback.
- Claimed time remains the source's own UTC start plus the selected offset, never corrected. Prior remains a 20 km square drawn by the independent custodian under the previous blind batch 3 rule. Independently per packet dx,dy=`(secrets.randbelow(2000001)-1000000)/100000` km, centre latitude round(lat+dy/111.19,4), centre longitude round(lon+dx/(111.19*cos(latitude)),4), cosine in radians; edges use centre latitude and half-side 10 km, six decimals. Save once, never redraw. Exact B3 rounding may leave an extreme boundary truth a few metres outside the nominal square; do not redraw for containment. Original draw/edge code hashes supplied by the independent custodian: `146a16e44622c5418412c58f5f1723a2543f56213fdbc80f52d9f8fdb1d9c406`, `42a17e7f494096adab9a922b79ad6a2f5db07bac6679381689f208fe3e8aae7a`.
- Flights remain adsb.lol globe_history, square+0.3 degrees, claimed time-1,200 s through window end+1,260 s, and the corresponding +7,200 s window for W, including day rollover. A uses donor selected audio's actual duration at the recipient claimed start. Unheard indexes the same archive days as in prev. Terrain follows prev: GLO-30 for dopplerprint, GLO-90 for reference; failed reference DEM may run without terrain and is recorded. Missing/unusable history is a miss where no answer can be produced.

## Scoring and report

- The independent custodian uses the prev hit rule: answer within1,000 m of published position, haversine R6,371 km. Crash, timeout, refusal, no-answer, unreadable/unfetched audio and missing/unrun row at the fixed processing stop are misses. Every selected recording stays in the denominator. A row with an unpinned version is a miss and listed. Published precision is retained and any >1km cases are reported separately without a post hoc denominator change.
- Report per entrant/arm: unconditional per-recording rate, detector-positive domain rate and the same by source, with hits/answers/denominators/status counts, source population shares, actual days/draws/places and window-rule counts. Detector errors stay in the unconditional denominator and are reported unknown, not negative. A's detector-positive domain is defined by the recipient's original recording. Report processing coverage and unfinished misses explicitly; this is a time-bounded end-to-end pipeline rate, not an estimate of unlimited eventual compute.
- Preserve prev's 95% percentile bootstrap over day draws, 10,000 resamples, seed20261105. The single-start systematic PPS design is not an independent-day sample; these retain prev's approximation, not a new exact-coverage claim. Also report recording-bootstrap and private-place-cluster bootstrap intervals (10,000 resamples, seeds20261106/20261107), recomputing the same weighted rate/domain ratio. The grouping rule is identical canonical published coordinate pairs across sources, privately HMAC-labelled by the independent custodian. These are published-point groups, not independently verified physical places. Groups stay private; this is recording-weighted prevalence with published-point clustering sensitivity, not equal-place population prevalence. Sparse/no-data domains are labelled. If a zero-hit bootstrap is [0,0], report zero hits plus a clearly labelled binomial score upper-bound diagnostic, never a certainty interval or a claim of achieved precision.
- Chance remains pi/400 =0.785398%, a nominal uniform-answer 1km-circle/20km-square comparator, not an exact boundary-corrected or flight-aware null. W and A are empirical controls. No above-chance significance or consensus claim is primary.
- The independent custodian independently reopens the fixed sample and terminal outputs, reconciles every row including explicit misses, and publishes aggregates only. Runner outputs retain packet, entrant, arm, pinned version/hash, status/exit code, answer-or-null, inferred clock-or-null, start/end/wall time, Slurm allocation and input hashes. Coordinates/squares remain in access-controlled runner/scorer inputs, not shared summaries.
